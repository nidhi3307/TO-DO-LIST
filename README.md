# To-Do List App (Tkinter GUI)

A simple graphical To-Do List application using Python's Tkinter.

## Features
- Add tasks
- Remove tasks
- Mark tasks as completed
- Tasks saved in `tasks.txt` for persistence
- Simple, interactive GUI

## Requirements
- Python 3.6 or higher
- Tkinter (usually included with Python)

## Usage
Run the app:

```bash
python todo_gui.py
